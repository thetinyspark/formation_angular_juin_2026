TP n°17 

- Créer un interceptor pour le cartService afin que ce dernier puisse communiquer de nouveau avec une API (donc on tire nos produits du panier depuis une API et on sauvegarde en utilisant également l'API)

- Cet interceptor devra intercepter les requêtes de type POST et GET afin 
de sauvegarder / restituer les données depuis le localstorage. 

Ainsi notre cartService sera fin prêt pour la prod tout en bénéficiant 
d'une simulation du serveur avec une persistence assurée par localStorage
